# AI-Driven Quant Research & Predictive Trading Platform

Advanced machine learning and quantitative trading platform built for financial forecasting, algorithmic trading, portfolio evaluation, reinforcement learning, and real-time market analysis.

---

# Features

- XGBoost factor models
- LSTM time-series forecasting
- Reinforcement Learning trading agents
- Regime-aware machine learning
- SHAP explainability
- Bayesian optimization with Optuna
- Walk-forward validation
- Ensemble learning
- Portfolio backtesting
- Real-time signal engine
- Risk management system
- Market microstructure analytics
- Live monitoring dashboard

---

- Python
